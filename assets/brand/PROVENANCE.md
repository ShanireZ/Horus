# Horus 品牌資產

本目錄是當前採用版本的完整自包含副本；與 `BetaPass/std/brand/horus/` 逐位元組鏡像。
生成、合成與檢核指令碼只保存在 `BetaPass/std/candidates/_build/`，不復制進專案。

## 當前檔案

| 檔案 | 用途 |
|---|---|
| `horus-logo-source.png` | 採用的 Logo 原生源或品牌定稿源 |
| `horus-logo-alpha.png` | 當前建置使用的透明中間源 |
| `horus-logo.png` | 1024×1024 透明 Logo 定稿 |
| `horus-badge-bg-source.png` | 橫版原生無字源圖 |
| `horus-badge-bg.webp` | 1248×416 無字橫版背景 |
| `horus-badge.webp` | 1248×416 帶字橫版定稿 |
| `horus-stage-bg-source.png` | 豎版原生無字源圖 |
| `horus-stage-bg.webp` | 1280×1600 無字豎版背景 |
| `horus.webp` | 1280×1600 帶字豎版定稿 |
| `prompts-horus.md` | Logo、橫版、豎版提示詞與合成規範 |
| `fonts/` | 實際合成使用的字體與現有授權文字 |

## 字體

Cinzel 用於單行 HORUS 字標；字體按 SIL Open Font License 1.1 使用。

## 版本紀律

這裡只保留當前採用版本。被否決的生成結果、帶 `v1` / `v2` 的過渡命名和舊建置中間圖不保留；需要重現時以本目錄源圖、提示詞和 BetaPass 內的指令碼為準。
