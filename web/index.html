HORUS

本地局域网考试监考系统

  • 纯检测 + 取证 不做网络与主机层阻断，只采集、留证
  • 元数据优先，图像为辅 前台窗口 / 进程 / 浏览器 URL / 剪贴板 / USB
  • 系统只初筛，人工裁决 可疑队列交监考员复核，机器不下结论

全部数据在局域网内流转，存在本地监考服务器上。唯一出网的是服务器侧的视觉识图 —— 送云前降采样并剥离元数据，原图永不出网。
